# Маскот: альпийский сурок-часовой

**Идея.** Альпийские сурки живут ровно там, где у наших клиентов проблемы: Бреннер, Готтард, Монблан. Когда сурок видит опасность, он встаёт на задние лапы и свистит, и колония успевает укрыться. zhol делает то же для офиса: предупреждает вечером накануне, пока ещё можно поменять план.

**Имя (на выбор):** *Fischio* (по-итальянски «свист»: понятно клиентам, говорит, что он делает) или *Suyr* (по-казахски «сурок», в пару к *zhol* — «дорога»).

**Эскизы** (Higgsfield, тот же стиль гравюры, что в деке; одна красная деталь — платок):

| Файл | Где использовать |
|---|---|
| `marmot-sentinel.webp` | главный образ: страница опроса, «спасибо», последний слайд питча |
| `marmot-avatar.webp` | аватар WhatsApp Business и LinkedIn (читается в маленьком круге) |
| `marmot-phone.webp` | объяснение продукта: «сурок показывает вечернее сообщение» |
| `marmot-pass.webp` | широкий баннер: 404, шапка рассылок, обложка поста |

**Правила.** Маскот живёт в контактах с людьми: опрос, сообщения, посты, 404. Ответы жюри, рынок, финплан и радар остаются строгими, без него. Больше одного сурка на странице не ставим.

## Набор поз для опроса (`site/assets/img/mascot/`, прозрачный фон, 480 px)

| Файл | Шаг опроса |
|---|---|
| `m1-truck` | 1 · сколько грузовиков |
| `m2-map` | 2 · как часто за границу |
| `m3-watch` | 3 · сколько времени на проверки |
| `m4-coin` | 4 · сколько стоил последний сбой |
| `m5-phone` | 5 · нужен ли вечерний WhatsApp |
| `m6-tag` | 6 · справедливая цена |
| `m7-cheer` | ответы отправлены |
| `m0-hello` | «спасибо», переслать коллеге |

Сгенерированы в Higgsfield с главным образом (`marmot-sentinel`) как референсом персонажа, поэтому сурок везде один и тот же. Новые позы делать так же: референсы — карта из дека и `marmot-sentinel`.
