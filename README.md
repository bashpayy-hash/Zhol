# zhol

**Which of tomorrow's loads will a restriction hit?** — каждый вечер zhol проверяет завтрашние рейсы транспортной компании на все запреты, дозирование в Куфштайне, закрытия, забастовки и протесты по маршруту и присылает диспетчеру **одно сообщение в WhatsApp** с вариантами: выехать раньше, позже, сменить перевал или придержать груз. Если проблем нет — молчит.

Команда: Alikhan · Inkara · Tomiris (Bocconi), TEF Ignition 2026.

Данные беты считает настоящий движок zhol при каждой сборке на Netlify (`scripts/build_site.py`, настройки в `netlify.toml`).

**Подключить GitHub к Netlify (1 минута, из браузера):** Netlify → проект `zhol-beta` → Project configuration → Build & deploy → *Link repository* → GitHub → `bashpayy-hash/Zhol`, ветка `claude/bold-franklin-t1lyqx` (или `main` после мержа). Настройки сборки подтянутся из `netlify.toml`. Дальше каждый push пересобирает сайт.

**Обновление данных дважды в день:** в Netlify создать Build hook, добавить его в GitHub как секрет `NETLIFY_BUILD_HOOK`; workflow `.github/workflows/refresh-site.yml` будет дёргать его в 06:15 и 16:45 по Риму (работает из ветки по умолчанию).

**Заявки из форм:** Netlify → zhol-beta → Forms. Уведомления на почту настраиваются там же (адрес должен быть участником команды Netlify).

## Как запустить

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q                 # 31 тест
python -m zhol demo sicily          # кейс из деки: забастовка на Сицилии, 18 окт 2026
python -m zhol demo brenner         # Бреннер: дозирование в Куфштайне, ночной запрет A12, закрытие Фрежюса
python -m zhol serve                # веб-консоль на http://127.0.0.1:8000
```

Другие команды:
- `python -m zhol bans 2026-11-07` — все национальные запреты на 3 дня;
- `python -m zhol extract "<текст новости>"` — извлечь событие из текста;
- `python -m zhol savings --trucks 20` — расчёт экономии и цены.

API-документация: `http://127.0.0.1:8000/docs`. Настройки (ключ Claude, WhatsApp Cloud API, токен админа) — в [.env.example](.env.example). Без ключей всё работает: извлечение — на правилах, WhatsApp — в консольном режиме (сообщения никуда не уходят).

## Что умеет MVP

- **Правила запретов в 7 странах** (IT, AT, DE, CH, FR, SI, PL). Включая итальянский календарь 2026 (DM 325/2025) с поправками для международных рейсов (+4 ч на въезд, −2 ч на выезд), австрийский ночной запрет с исключением для малошумных машин и зимний ночной запрет на A12 с 20:00.
- **19 коридоров и 18 узких мест**: Бреннер, Luegbrücke, Куфштайн, A12, Тарвизио, Тауэрн, Готтард, Сан-Бернардино, Фрежюс, Монблан, Вентимилья, паром через Мессинский пролив и другие.
- **Симуляция рейса**: ETA в каждой точке, правила вождения ЕС 561/2006, паромы, швейцарская таможня, исключения (скоропорт, малошумные машины), направление движения.
- **Варианты и стоимость**: выехать раньше / позже, сменить маршрут, придержать. Стоимость считается по модели компании: €100 за час простоя (закон), км, платные дороги, опоздание.
- **Извлечение событий из текста**:
  - Claude (`claude-opus-5-5`, строгая JSON-схема, проверка цитаты);
  - запасной вариант на правилах (IT/DE/FR/EN);
  - парсер DATEX II для национальных точек доступа ЕС.
- **Ручная проверка**: каждое событие одобряет человек; время проверки измеряется.
- **WhatsApp Cloud API**: шаблон вне 24-часового окна, полный текст внутри окна, ответы диспетчера `1` / `2` / `0`, проверка подписи вебхука.
- **Метрики пилота и «журнал экономии»**: точность, ложные тревоги, пропуски, время проверки, подтверждённая экономия.
- **Веб-консоль** в вашем дизайне ([design/](design/DESIGN.md)): Tonight, Review, Loads, Alerts, Pilot, Savings.

## Что нужно сделать команде (то, что нельзя сделать из кода)

1. **WhatsApp Business**:
   - завести номер в Meta Business Manager;
   - отправить шаблон `zhol_load_alert_v1` на одобрение (категория *utility*, текст в docs/04 §4.7);
   - прописать `WHATSAPP_*` в `.env`.
2. **Ключ Anthropic API**: `ANTHROPIC_API_KEY` в `.env`, чтобы новости разбирал Claude, а не правила.
3. **Доступ к данным**:
   - бесплатная регистрация на CCISS (DATEX II Италии);
   - запрос доступа к ASFINAG / mobilitydata.gv.at;
   - вбить календарь дозирования Тироля по шаблону `zhol/data/calendars/examples/`.
4. **Источники**: ключевые факты сверены с первоисточниками — лог в [docs/07-source-verification.md](docs/07-source-verification.md). С вашего ноутбука осталось скачать: итальянский декрет (сайт MIT не открывается из облака) и календарь Luegbrücke от ASFINAG (блокирует облачные IP). В декабре внести декрет MIT на 2027 год.
5. **Начать аутрич**: [outreach/README.md](outreach/README.md).
