## Как подключить к новому Claude Code

1. Положи эту папку в корень нового репозитория, например в `brand/`.
2. Добавь в `CLAUDE.md` (или `AGENTS.md`) нового проекта:

```markdown
# Прочитай до первой правки
1. `brand/PRINCIPLES.md` — правила владельца. Это требования, а не пожелания.
2. `brand/MASCOT.md` — маскот Веспи: идентичность, промпты, где ставить.
Отвечай по-русски, ничего не спрашивай — делай и коротко говори, что выбрал.
В каждом финальном ответе давай ссылку на живой сайт.
Каждое новое решение владельца записывай в DESIGN.md с его цитатой.
```

3. Для генераций нужен Higgsfield MCP. В том же аккаунте эталоны маскота
   доступны по ID (см. `MASCOT.md`, раздел 4); в другом — загрузи эталоны из
   `mascot/originals/references/`.
